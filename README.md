# VivaPenedo 

Um guia web dinâmico e interativo para centralizar informações sobre turismo fluvial, gastronomia e vida noturna na cidade de Penedo, Alagoas. 

Este projeto foi desenvolvido como requisito de avaliação (AB1) para a disciplina de **Programação Web I**, ministrada pelo professor Gustavo Miranda, no curso de Sistemas de Informação da Universidade Federal de Alagoas (UFAL) - Campus Arapiraca / Unidade Penedo.

## 🎯 O Problema e a Solução
**Problema:** Moradores, estudantes universitários e turistas enfrentam dificuldades para encontrar informações centralizadas sobre horários de lanchas/catamarãs no Rio São Francisco, restaurantes abertos em dias de baixo movimento e a agenda de eventos noturnos, dependendo quase exclusivamente do "boca a boca" ou postagens efêmeras no Instagram.

**Solução:** O *VivaPenedo* atua como um portal unificado onde o usuário pode visualizar passeios fluviais (com link direto para agendamento no WhatsApp), conferir quais restaurantes estão abertos/fechados no momento e explorar opções de lazer, fomentando o comércio e o turismo local.

## 💻 Tecnologias e Requisitos Técnicos Aplicados
O projeto foi construído seguindo rigorosamente os critérios técnicos exigidos na ementa da disciplina:
- **React.js:** Divisão da interface em componentes funcionais reutilizáveis (`Navbar`, `Hero`, `Passeios`, `Gastronomia`, `Footer`).
- **HTML Semântico:** Estruturação correta das páginas utilizando tags como `<header>`, `<main>`, `<section>`, `<article>` e `<footer>`.
- **CSS Puro & Flexbox:** O layout responsivo, a movimentação das caixas, a estilização de textos (hierarquia de fontes) e o tratamento de imagens (cover, border-radius) foram feitos do zero utilizando CSS3 e Flexbox, sem dependência de frameworks externos como Tailwind ou Bootstrap.
